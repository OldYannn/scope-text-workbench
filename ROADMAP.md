# SCOPE roadmap

SCOPE is currently Pre-alpha. Dates are intentionally omitted until the corresponding technical risks have been validated.

## Milestone 0 — Repository foundation

- [x] Confirm the desktop architecture direction
- [x] Establish the repository and core project documents
- [x] Record the desktop/sidecar architecture decision
- [x] Define the initial versioned sidecar protocol
- [x] Add the minimal React/Tauri desktop shell
- [x] Add the Python engine package and contract tests
- [x] Add initial CI, linting, formatting, and build checks
- [ ] Validate progress, cancellation, failure recovery, and reproducibility metadata with a non-research diagnostic operation
- [ ] Package the Python sidecar without requiring a system Python
- [ ] Validate installers on Windows x64, macOS arm64, and macOS x64
- [ ] Replace development template icons with approved SCOPE brand assets
- [ ] Compare License options and obtain project-owner approval

## Milestone 1 — Corpus management and text cleaning

Planned after Milestone 0 is accepted. Scope is defined in `PROJECT_BRIEF.md`.

## Later milestones

Tokenization, frequency analysis, co-occurrence analysis, the research audit trail, optional model-provider adapters, experimental AI coding, and the first Public Alpha will follow the milestone sequence in `PROJECT_BRIEF.md`.

Milestone completion always requires the relevant build, test, lint, format, documentation, privacy, and reproducibility checks described in `AGENTS.md`.
